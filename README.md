# Base de Datos Hospital Wellmeadows

Caso de estudio de diseño e implementación de una base de datos relacional para el Hospital Wellmeadows.

## Contenido del proyecto

- Modelo entidad-relación
- Matriz de entidades y atributos
- Normalización de tablas
- Implementación de la base de datos en SQL

## Archivos

- `MAPA ENTIDAD ATRIBUTO WELLMEADOWS.png`: modelo de entidades y atributos.
- `Matriz de hospital.PNG`: matriz utilizada para el diseño de la base de datos.
- `Normalizacion de hostipital.pdf`: proceso de normalización de las tablas.
- `Wellmeadows_Hospital.sql`: implementación de la base de datos.

## Conceptos aplicados

- Diseño de bases de datos relacionales
- Normalización de tablas
- Primera Forma Normal (1FN)
- Segunda Forma Normal (2FN)
- Tercera Forma Normal (3FN)
- Claves primarias y foráneas
- Relaciones entre entidades

## Tecnologías

- SQL
- SQL Server
